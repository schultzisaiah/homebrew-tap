# Homebrew tap

```sh
brew trust schultzisaiah/tap
brew install --cask schultzisaiah/tap/psst-reminders
```

Homebrew asks you to trust a tap before it loads anything from it; the first line does that once.

| Cask | App |
|---|---|
| `psst-reminders` | [Psst](https://github.com/schultzisaiah/psst-macos): meeting reminders for macOS that are hard to miss and nice to look at |

Psst updates itself, so `brew upgrade` leaves it alone unless you add `--greedy`. Each stable release updates the cask here automatically.
